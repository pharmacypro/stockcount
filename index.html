คำถามที่พบบ่อย (FAQ)
📷 สแกนบาร์โค้ดไม่ได้ ทำยังไง?

1. ตรวจสอบระยะห่าง: ควรห่าง 10-15 ซม. (ประมาณความยาวปากกา)

2. ตรวจสอบแสง: ควรมีแสงสว่างพอ หรือใช้ไฟฉายช่วย

3. ตรวจสอบบาร์โค้ด: ไม่ยับ ไม่ซีดจาง ไม่มีรอยขีดข่วน

4. กดปุ่ม "โฟกัส" เพื่อปรับกล้อง

5. ถ้ายังไม่ได้ กด "ใส่รหัส" เพื่อพิมพ์บาร์โค้ดด้วยมือ

📦 สินค้าไม่มีในระบบ ทำยังไง?

1. กดปุ่ม "+ เพิ่มสินค้า" ข้างๆ ช่องค้นหา

2. กรอกชื่อสินค้า (จำเป็น) และข้อมูลอื่นๆ (บาร์โค้ด, ราคา, หมดอายุ)

3. ถ้ามีบาร์โค้ด ให้ใส่ด้วย ระบบจะจำให้อัตโนมัติ

4. กด "บันทึกสินค้า" แล้วนับได้ทันที

✏️ นับผิดแล้วแก้ยังไง?

1. ที่ "รายการนับล่าสุด" คลิก ✏️ (ดินสอ) ข้างรายการนั้น

2. เปลี่ยนจำนวนแล้วกด "บันทึก"

3. หรือกด 🗑️ (ถังขยะ) เพื่อลบแล้วนับใหม่

4. หรือกดปุ่ม "นับใหม่" ข้างๆ ปุ่มยืนยัน

📊 ดูรายงานยังไง?

1. นับเสร็จแล้วกด "สรุปผล" ที่แท็บนับสต็อก

2. หรือไปที่แท็บ "รายงาน" เพื่อดูข้อมูล

3. กด Export เพื่อส่งออก CSV/Excel/PDF

4. มี Export พิเศษ: ตู้/ชั้น, Master Barcode, History

💾 ข้อมูลหายไปทำยังไง?

1. ระบบมี Auto-Backup ฉุกเฉิน เมื่อเปิดหน้าจะถามกู้คืน

2. แนะนำให้กด "สำรองข้อมูล" ทุกครั้งที่นับเสร็จ

3. ถ้าข้อมูลหาย ให้ใช้ไฟล์ Backup ที่บันทึกไว้กู้คืน

4. ควร Backup ไว้ในหลายที่ (มือถือ, คอม, Google Drive)

🌐 ใช้หลายเครื่องพร้อมกันได้ไหม?

1. ได้! ใช้ Google Sheets Sync เป็นตัวกลาง

2. ตั้งค่า API Key และ Spreadsheet ID ในหน้า Settings

3. แต่ละเครื่องกด "ซิงค์ขึ้น Google Sheets" เพื่ออัปเดต

4. แนะนำให้แบ่งโซนนับ (คนนับหน้าร้าน, คนนับหลังร้าน)
