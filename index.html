กรอกข้อมูลเพื่อเชื่อมต่อกับ Google Sheets / Google Drive / OneDrive

วิธีขอ API Key (ฟรี)
  1. ไปที่ Google Cloud Console
  2. สร้าง Project หรือเลือก Project ที่มีอยู่
  3. เปิดใช้งาน Google Sheets API และ Google Drive API
  4. ไปที่ Credentials → สร้าง API Key
  5. คัดลอก API Key มาใส่ในช่องด้านบน
  6. สำหรับ OneDrive: ไปที่ Azure Portal และสร้าง App Registration
